# 工程决定

## P0 首选桥接

先验证游戏 Lua 使用 `TheSim:QueryServer` 主动访问 `127.0.0.1` 上的 Python HTTP 服务。[Klei 653007 更新](https://kleiforums.com/game-updates/dst/653007-r2465/)允许客户端和服务端查询本机地址；当前安装的脚本包中也能看到 `QueryServer` 的 POST 调用。此阶段只做状态与回执，不下发动作。

采用私有、独立的本地测试世界，服务端 Mod 从威尔逊实体读取最少状态。探针仅在用户于游戏界面启用后运行，不强制加载，不碰现有世界。真实加载、服务端上下文、回调和返回体都以游戏内日志判定。

若 HTTP 在当前构建受阻，再根据实际错误评估 `unsafedata` 文件交换；暂不放宽沙箱设置。
