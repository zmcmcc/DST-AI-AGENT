# Wilson Survival Agent

本项目从 P0 接口探针开始，逐步验证 macOS／Steam 版《饥荒联机版》中的威尔逊自主控制。

当前稳定化版本 0.25.1：探索移动只在真正终止后上报 `arrived`；前两天规划器和游戏端都会拒绝已知沼泽路线，误入沼泽时游戏端尝试返回最近的安全位置；危险处理增加 `NORMAL → EVADE → RECOVER` 状态。新增独立的远距离原生采摘基准探针与时序记录，实机结果待验证。采集停顿、路边资源漏捡和区域收集仍是开放问题，见 [稳定化进度](docs/stabilization-0.25.md)。尚未接入 Jev。

## 连续自主测试

1. 在单独的私有测试世界启用 `Wilson Survival Agent (Test)`，选威尔逊进入。Mod 文件由 Codex 同步，无需手动复制。
2. 进入世界后自主模式自动开始。`curl http://127.0.0.1:8765/survival/status` 可看当前目标和完成数；`curl -X POST http://127.0.0.1:8765/survival/stop` 可停止本轮世界的自主模式。
3. 桥接日志写入 `probe/bridge.out.log`；在项目目录用 `tail -f probe/bridge.out.log` 查看。游戏内气泡仍会显示角色行动意图。

下一轮先运行独立原生采摘基准，确认 `Locomotor:PushAction` 的远距离目标动作结果。游戏内气泡说明当前意图；桥接日志记录候选分数、过滤原因、动作回执和时序。`/survival/status` 在首夜结束后记录生存结果、夜间有光和无光的采样次数。

## P0 探针

1. 早期探针使用 Terminal 手动运行桥接服务；当前版本由用户登录服务启动，仍只监听 `127.0.0.1:8765`。
2. Mod 已安装在 DST 应用包的 `Contents/mods/wilson_p0_probe`。修改后由 Codex 同步游戏目录中的文件，无需手动复制。
3. 启动或重启 DST，在主菜单的 Mod 列表中确认出现 `Wilson Survival Agent (Test)`。在游戏界面新建仅供测试的私有世界，只启用这个 Mod，选威尔逊进入。
4. 从 `probe/bridge.out.log` 观察 `seq=... prefab=wilson`，DST 日志中的 `[Wilson P0]` 可用于核对回执。

游戏测试已连续收到 HTTP 200 匹配回执，并通过了 Python 服务断开与恢复测试。短距离移动探针已在游戏内执行一次，日志显示向东移动约 1.55 游戏单位，随后继续正常回传状态。详细结果见 `docs/progress.md`。

0.3.0 的扩展观察已在游戏内验证：生命、饥饿、理智和附近浆果丛、小树苗都能通过本机服务读取。`http://127.0.0.1:8765/latest` 可查看最近一次观察。

0.4.0 的指定目标采集探针已在游戏内采到一份草，目标变为不可采，状态回传继续正常。人工中断尚待验证。

0.5.0 的人工接管探针已在游戏内验证：用户按反方向键后，威尔逊按人工方向继续移动，Mod 定时器没有停止这次人工移动。

0.6.0 的显式停止命令已同步到游戏目录，尚待游戏内验证。

0.7.0 的自主采集循环已在真实游戏里连续采到两株草和一株小树苗，三次背包增量均为 1。进入测试世界后，在另一个终端运行 `curl -X POST http://127.0.0.1:8765/auto/start` 开始；`curl http://127.0.0.1:8765/auto/status` 查看计数。只有白昼、生命和饥饿均不少于 75、附近观察不到青蛙时，才选择 8 游戏单位内可采的草、小树苗或浆果丛。完成五次或当前范围内没有可采目标时结束。

桥接服务启动后，Terminal 会立即显示监听提示；进入世界后约每十次状态上报显示一行摘要，选择目标和动作结果会立即显示。尚未进入世界时没有游戏状态可显示。以后由用户在自己的 Terminal 启动服务，避免日志只出现在 Codex 的后台终端。

0.8.0 已在游戏中验证：两次面向草的目标移动都报告 `arrived`，客户端移动预览已执行，用户确认第二次移动出现正常走路动画。0.11.0 的首次连续测试中，用户看到威尔逊探索、采草和树枝、避开怪物并制作火炬；黄昏热更新后日志记录继续探索、采食并吃下、换备用火炬。0.15.0 实机测试中，角色完成多段探索和地面拾取，但三次浆果采摘失败，路线交接显得停顿，开局区域缺草导致长期搜索。0.16.0 测试确认采摘能完成、自动模式能启动；在缺草地图中仍以探索为主，进入黄昏后停止。0.17.0 测试确认黄昏继续搜索并在夜间举起火炬；夜间随后原地等待，探索移动仍频繁停顿，未拾取长矛和牛毛。0.18.0 观察到更多探索、拾取和砍树行为；目标交互有停顿、砍树间歇、遗骸物资只拾一件，这些问题形成了 0.19.0 的改动依据。
